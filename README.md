# PKPIM Official Website

Official website for **Persatuan Kebajikan dan Perkhidmatan Insan Sabah (PKPIM)**.

The website is being developed to provide information about PKPIM, its charitable programs, community activities, and ways for the public to support its initiatives.

> Website currently under development.

---

## Current Pages

### Home
Main introduction to PKPIM, including:
- Background
- Vision and mission
- Core values
- Programs
- Contact information

### Kempen Derma Darah
Information about PKPIM's blood donation campaign, including:
- Kempen Derma Darah 2026
- 2026 event schedule
- Campaign activities
- Strategic partners
- Event gallery
- 2027 campaign coming soon

### ROTIKAN
ROTIKAN is a social enterprise initiative supporting autism education in Sabah through bread sales.

The page currently includes:
- ROTIKAN program background
- Autism education information
- ROTIKAN statistics
- Tabung Pendidikan Autisme
- Total funds collected
- ROTIKAN sales station map
- Program support information

---

## Technology Used

The website is built using:

- HTML5
- CSS3
- JavaScript
- Google Fonts
- OpenStreetMap

No frontend framework is currently used.
